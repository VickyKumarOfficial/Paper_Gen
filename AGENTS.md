# Agent Execution Rules and Documentation Standards

## Operational Constraints & Principles

The following core principles govern all code generation, refactoring, documentation, and task execution within the **Niera Grading System** project:

1. **Strict Scope Control**: AI agents and developers must strictly adhere to requested tasks without jumping to unrequested work or scope creep.
2. **Feature Proof & Authenticity Documentation**: For every feature or code addition, comprehensive proof and explanation must be documented in `/docs` demonstrating the working principle, performance efficiency, and functional correctness.
3. **Flawless Code Quality**: Code must be optimal, robust, and free of security flaws or edge-case bugs.
4. **Explicit Change Authorization**: No existing files or architecture components may be changed without explicit user permission.
5. **Centralized Documentation**: All rules, architecture specifications, and feature proofs must be organized in the `/docs` folder as markdown files.
